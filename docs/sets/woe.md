# Wilds of Eldraine census

Wilds of Eldraine (WOE) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-17 from MTGJSON's set list against `data/cards/`
at e30673b4 (#8329). The set list is `data/decks/sets/woe/all.txt`, which the
suite reads, so every card of the set stays in the pool.

WOE has 281 card names, 332 faces (MTGJSON 5.3.0+20261114); 300 faces were
missing, 251 cards (194 normal, 49 adventure, 8 saga).
