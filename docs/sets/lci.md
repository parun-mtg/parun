# The Lost Caverns of Ixalan census

The Lost Caverns of Ixalan (LCI) cards not yet in the pool, and which wait on
a capability. Derived 2026-11-17 from MTGJSON's set list against
`data/cards/` at e7178e0b (#8231). The set list is
`data/decks/sets/lci/all.txt`, which the suite reads, so every card of the set
stays in the pool.

LCI has 291 card names, 327 faces (MTGJSON 5.3.0+20261114); 289 faces were
missing, 257 cards (225 single-faced, 31 transform, 1 adventure).
