# Bloomburrow census

The Bloomburrow (BLB) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-15 from MTGJSON's set list against `data/cards/`
(#7967). The set list is `data/decks/sets/blb/all.txt`, which the suite reads,
so every card of the set stays in the pool.

BLB has 279 card names (MTGJSON 5.3.0+20261114; 269 `normal`, 10 Classes);
41 were already in the pool, 238 missing (9 of them Classes).

| Place | Cards |
| --- | --- |
| Added by the census (#7985) | 42 |
| Batches #7976 to #7984 | 181 |
| Capability issues #7969 to #7975 | 15 |

- Trend: the first dry run translated 42 of the 238 missing; 15 needed a
  capability.
- Batch 9 (#7984) was blocked by batch 5 (#7980), which wrote "Whenever you
  gain or lose life during your turn" first (Moonstone Harbinger; Wax-Wane
  Witness reuses it). No other shape was shared across batches.
- Translate skips Classes, so the 9 missing Classes were classified by hand.
  #7972 (valiant) carried nine cards, one edit site. The translator was not
  widened.

## Decks

None is committed: decks are optional, so `data/decks/sets/blb/` holds only
the set list, 279 names.
