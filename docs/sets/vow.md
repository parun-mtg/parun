# Innistrad: Crimson Vow census

The Innistrad: Crimson Vow (VOW) cards not yet in the pool, and which wait on
a capability. Derived 2026-11-20 from MTGJSON's set list (AllPrintings of
2026-10-26) against `data/cards/` at 38fa9e62 (census #9114, tracker #9113).
The set list is `data/decks/sets/vow/all.txt`, which the suite reads, so every
card of the set stays in the pool.

VOW has 321 face names, from 337 `normal` and 150 `transform` printings; the
set list holds its 272 card names, 49 of them transforming. 261 faces (216
cards) were missing.
