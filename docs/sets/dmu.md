# Dominaria United census

The Dominaria United (DMU) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-19 from MTGJSON's set list (AllPrintings of
2026-11-18) against `data/cards/` at 2c97f91c (census #8874, tracker #8873).
The set list is `data/decks/sets/dmu/all.txt`, which the suite reads, so every
card of the set stays in the pool.

DMU has 271 face names, from 426 `normal` and 10 `saga` printings; no card has
a second face, so the set list holds all 271. 195 faces were missing.

- The six read ahead sagas were hand-written, since `candidates.jq` skips the
  saga layout; the three planeswalkers were hand-written (translate rejects

- No shape new to the pool was shared across batches, so no batch blocked
  another. #8877 (Squee) and #8878 (Silver Scrutiny) both extend
  `Parun.Types.CastingPermission`, so #8878 was linked as blocked by #8877;
  #8879 was linked as blocked by #8876, both reaching cost reductions.
