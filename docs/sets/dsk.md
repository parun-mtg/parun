# Duskmourn: House of Horror census

The Duskmourn: House of Horror (DSK) cards not yet in the pool, and which wait
on a capability. Derived 2026-11-15 from MTGJSON's set list against
`data/cards/` (#7845). The set list is `data/decks/sets/dsk/all.txt`, which
the suite reads, so every card of the set stays in the pool.

DSK has 276 card names (MTGJSON 5.3.0+20261114; 299 face names; 252 `normal`,
one `saga`, 23 Rooms of two faces each); 31 were already in the pool, 245
missing (267 faces, 22 of the cards Rooms).

| Place | Cards |
| --- | --- |
| Added by the census (#7876) | 22 |
| Batches #7866 to #7875 | 205 |
| Capability issues #7850 to #7864 | 18 |

- Trend: the first dry run translated 22 of the 245 missing; 18 needed a
  capability.
- Translate skips Rooms and Sagas, so the 22 missing Rooms and The Tale of
  Tamiyo were classified by hand. #7858 carried three cards and #7860 two,
  one edit site each. The translator was not widened.
- Batches 2 to 10 were blocked by batch 1 (#7866), which wrote "enters tapped
  unless a player has 13 or less life" (ten lands) and the delirium wording
  first.

## Decks

None is committed: decks are optional, so `data/decks/sets/dsk/` holds only
the set list, 276 names, each Room by MTGJSON's joined name (`A // B`).
