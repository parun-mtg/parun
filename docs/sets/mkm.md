# Murders at Karlov Manor census

Murders at Karlov Manor (MKM) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-16 from MTGJSON's set list against `data/cards/`
at e13eac11 (#8147). The set list is `data/decks/sets/mkm/all.txt`, which the
suite reads, so every card of the set stays in the pool.

MKM has 279 card names, 285 faces (MTGJSON 5.3.0+20261114); 237 faces were
missing, 233 cards (Scryfall layouts: 220 normal, 9 case, 3 split, 1
adventure).
