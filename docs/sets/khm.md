# Kaldheim census

The Kaldheim (KHM) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-28 from MTGJSON's set list (AllPrintings of
2026-11-24) against `data/cards/` at 30da3d84 (census #10121, tracker
#10120). The set list is `data/decks/sets/khm/all.txt`, which the suite
reads, so every card of the set stays in the pool.

KHM has 305 whole card names from 354 `normal`, 66 `modal_dfc` and 20 `saga`
printings; the set list holds the 305, each modal double-faced card by
MTGJSON's joined name. The census counted 234 missing (14 modal
double-faced, 18 Sagas).

- Trend: the first dry run translated 37 of the 234 missing; 8 cards (7
  issues) needed a capability.
- No KHM card's whole text is keywords. Translate skips every `modal_dfc`
  and `saga` card and stops at planeswalker loyalty fields, so those were
  hand-written.
- KHM's "you may pay N. If you do, create a token, then attach this
  Equipment to it" wording was new to the pool: batch 3 (#10131: Draugr's
  Helm, Dwarven Hammer, Elven Bow) wrote it first, and batches 4 (#10132,
  Giant's Amulet) and 10 (#10138, Valkyrie's Sword) were linked as blocked by
  it.
- Cosmos Charger (#10125) and Karfell Harbinger, Niko Defies Destiny
  (#10126) both touch the foretell action's payment: #10125 was linked as
  blocked by #10126.
