# Outlaws of Thunder Junction census

The Outlaws of Thunder Junction (OTJ) cards not yet in the pool, and which
wait on a capability. Derived 2026-11-16 from MTGJSON's set list against
`data/cards/` (#8028). The set list is `data/decks/sets/otj/all.txt`, which
the suite reads, so every card of the set stays in the pool.

OTJ has 276 card names (MTGJSON 5.3.0+20261114; every printing `normal`); 31
were already in the pool, 245 missing.
