# Final Fantasy census

The Final Fantasy (FIN) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-14 from MTGJSON's set list against `data/cards/`
(#7569). The set list is `data/decks/sets/fin/all.txt`, which the suite reads,
so every card of the set stays in the pool.

FIN has 312 card names (MTGJSON 5.3.0+20261114; 344 face names; 262 `normal`,
27 `transform`, 15 `saga`, 5 `adventure`, 3 `meld` counting Ragnarok, Divine
Deliverance as its own name); 25 were already in the pool, 287 missing.

| Place | Cards |
| --- | --- |
| Added by the census (#7609) | 43 |
| Batches #7586 to #7597 | 231 |
| Capability issues #7574 to #7585, and open #7564 | 13 |

- Trend: the first dry run translated 43 of the 287 missing; 13 needed a
  capability.
- Translate takes only single-faced `normal` cards, so the 49 transform,
  saga, adventure and meld names went to batches by reading. The translator
  was not widened.
- Many batch cards carried a "verify" clause the census did not settle.

## Decks

None is committed: decks are optional, so `data/decks/sets/fin/` holds only
the set list, 311 names. It writes each transforming card, Saga creature and
Adventure land by MTGJSON's joined name, and Fang, Fearless l'Cie and
Vanille, Cheerful l'Cie by their own faces, as their pool cards name them.
Ragnarok, Divine Deliverance is not listed: it is no card of its own, only
half of each meld card's back (CR 713.1), kept in
`vanille-cheerful-lcie.json`.
