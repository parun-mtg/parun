# The Brothers' War census

The Brothers' War (BRO) cards not yet in the pool, and which wait on a
capability. Derived 2026-11-19 from MTGJSON's set list (AllPrintings of
2026-11-17) against `data/cards/` at b4d50273 (census #8824, tracker #8823).
The set list is `data/decks/sets/bro/all.txt`, which the suite reads, so every
card of the set stays in the pool.

BRO has 280 face names: 253 `normal` and 18 `prototype` cards, and three meld
pairs, whose three melded back faces are not cards of their own (CR 713.5a),
so the set list holds 277 names. 237 faces were missing.
