# Magic Online Avatars census

The Magic Online Avatars (PMOA) cards not yet in the pool, and which wait on
a capability. Derived 2026-11-26 from MTGJSON's set list (AllPrintings of
2026-11-26) against `data/cards/` at 4ed44bdf (census #9813, tracker #9812).
The set list is `data/decks/sets/pmoa/all.txt`, which the suite reads, so
every card of the set stays in the pool.

PMOA has 74 card names (85 printings), every one a digital-only `vanguard`
layout card (CR 313); none was in the pool, 74 missing.
